# 十四、概率生成规则

不得主观随意填写概率。

概率必须综合：

> **昨日内生状态 + 外部冲击F + 指数自身属性 + 市场情绪**

形成先验概率。

定义：

* `P_up`
* `P_flat`
* `P_down`

必须满足：

> **P_up + P_flat + P_down = 100%**

概率必须保持在：

> **0%～100%**

---

# 十五、概率解释标准

概率不是“预测确定性”。

例如：

> 上证上涨概率62%

只能解释为：

> 当前信息集合下，上涨方向属于优势情景，但仍存在38%的非上涨概率。

禁止使用：

* 必涨
* 必跌
* 稳涨
* 稳跌
* 100%确定
* 无风险

---

# 十六、Pivot Points运行区间

必须使用T-1：

* H = 最高价
* L = 最低价
* C = 收盘价

计算：

### 中枢

> P = (H + L + C) / 3

### 第一压力

> R1 = 2P - L

### 第二压力

> R2 = P + (H-L)

### 第一支撑

> S1 = 2P - H

### 第二支撑

> S2 = P - (H-L)

所有计算结果保留合理的小数位。

禁止凭空生成支撑压力。

# 十八、09:25竞价验证条件

每个指数必须提前设置验证条件。

---

## 预测强化

满足：

* 竞价方向与主场景一致
* 且竞价明显放量
* 核心权重/核心板块同步

则：

> 主场景概率提高5～10个百分点。

---

## 预测维持

满足：

* 竞价基本平稳
* 开盘幅度在±0.1%左右
* 成交没有明显异常
* 核心逻辑没有被破坏

则：

> 概率变化控制在±2个百分点以内。

---

## 预测反转

满足：

* 竞价方向与主场景严重背离
* 例如主场景看涨，但指数明显低开
* 同时竞价成交异常放大
* 跌停家数明显增加
* 核心权重同步走弱

则：

> 下调主场景概率15～25个百分点，并重新分配至其他场景。

注意：

> **不得让概率总和超过或低于100%。**

# 十九、竞价成交量定义

“竞价放量”必须有明确基准。

优先采用：

> 今日09:25竞价成交额 ÷ 过去20个交易日09:25平均竞价成交额

定义：

| 比率        | 状态   |
| --------- | ---- |
| ≥1.20     | 明显放量 |
| 1.05～1.20 | 温和放量 |
| 0.95～1.05 | 正常   |
| <0.95     | 缩量   |

如果无法获取20日竞价历史数据：

> 标记“竞价历史基准未获取”，不得虚构。

# 二十、09:25概率更新

概率更新必须满足：

> **后验概率仍然为100%。**

例如：

08:30：

| 状态 |  概率 |
| -- | --: |

| 震荡 | 23% |
| 下跌 | 15% |

如果09:25出现明显利空竞价：

可以更新为：

| 状态 |  概率 |
| -- | --: |
| 上涨 | 39% |
| 震荡 | 28% |
| 下跌 | 33% |

> 总概率 ≠ 100%。

# 二十一、15:00结果验证

收盘后记录：

### Direction Hit

预测上涨：

> 收盘 > 昨收 → 命中

预测下跌：

> 收盘 < 昨收 → 命中

预测震荡：

> 收盘位于预设震荡区间 → 命中

---

### Probability Score

记录：

> Brier Score

用于评价概率是否真正具有校准能力。

---

### Path Hit

判断：

> 实际盘中路径是否符合08:30预测的主/次/风险场景。
