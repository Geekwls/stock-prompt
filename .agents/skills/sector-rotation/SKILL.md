# A股近5日板块轮动与节奏复盘引擎

> 基于“资金性质（机构 vs 游资）+ 产业链传导 + 状态转移矩阵 + 主线衰竭指数 (SEI) + 高低切博弈 + 次日盘前跟踪矩阵”的 5 日市场轮动复盘框架。

执行分析前必须读取并遵循 [A股研究公共契约](references/common-research-contract.md) 与 [工具调用配方](references/tool-recipes.md)。

## 一、角色定位与意图映射

执行近 5 个交易日（T-4 至 T 日）资金迁移分析，聚焦：总量环境定调、机构趋势 vs 游资连板角逐、轮动状态转移、主线衰竭 (SEI) 及次日高低切跟踪。

### 🗣️ 口语化自然语言意图映射 (Natural Language Intent Mapping)
当用户输入以下非标准化口语提问时，自动路由并激活本 Skill 执行 5 日轮动分析：
- **板块轮动**：“最近哪几个板块在轮动”、“这周主线是谁”、“主力资金最近几天在往哪跑”、“5日轮动怎么看”
- **高低切换**：“现在去哪个板块比较安全”、“高位题材还能不能追”、“有什么低位补涨板块推荐”
- **轮动指令**：“板块轮动”、“5日复盘”、“行业轮动”、“主线衰竭分析”

## 二、数据获取与覆盖率审计

1. **时间锚定**：以最近已收盘交易日（T日 15:00 完场数据）为终点，向前倒推 5 个交易日（T-4 至 T 日）。
2. **工具调用路由**：优先调用 MCP `get_rotation_context` 一次性获取全 5 日指数K线、行业资金流、情绪序列与主线量价；未挂载 MCP 时平滑降级为定向搜索。具体调用配方与降级规则见 `references/tool-recipes.md`。
3. **覆盖率门槛**：计划权重为 T日 40%、T-1日 30%、T-2日 20%、T-3与T-4各 5%。覆盖天数不足 3 日或有效权重低于 70% 时，强制禁用 5 日量化分，仅输出定性观察。

## 三、状态转移矩阵与核心量化模型

模型负责特征归类与风险分档，精确计算统一调用 `scripts/calculate.py` 纯函数库（参见 `references/tool-recipes.md`）：

### 1. 资金轮动 4 种状态转移矩阵
- **State 1: 主线主升**：核心板块成交占比 $\ge 8\%$，连续 3 日阳线，产业链共振齐涨；
- **State 2: 畏高切低/补涨**：核心主线高位滞涨，资金挖掘同属性低位个股或细分赛道补涨；
- **State 3: 避险防御**：题材高位杀跌退潮，资金向高股息、红利、大银行抱团防守；
- **State 4: 冰点衰退**：涨停 $<20$ 家，跌停蔓延，高位股连续 A 杀，维持防守等待出清。

### 2. 主线衰竭与背离指数 (Sector Exhaustion Index, SEI: 0–100 分)
$$\text{SEI} = \text{量价背离度}(0\text{-}40) + \text{接力与炸板风险}(0\text{-}30) + \text{资金溢出与高低切}(0\text{-}30)$$
- **SEI 判定基准**：0–30分【动能充沛】；31–60分【良性分歧】；61–80分【动能严重衰竭/高低切确立】；81–100分【全面退潮踩踏】。调用 `calculate_sector_exhaustion` 计算。

### 3. 5 日情绪温度加权分
- 每日日度情绪分结合连板晋级率、红盘率与炸板率计算后，按 5 日权重调用 `calculate_5d_sentiment_score` 归一化输出。

## 四、报告输出模版与穿透指引

按以下结构输出完整 5 日轮动报告（缺失维度标注 `N/A`）：
1. **零、总量环境与轮动状态定调**：5 日成交额走势、主力资金偏好、总量定性与 State 1–4 状态定调。
2. **一、主线角逐与资金博弈（机构 vs 游资）**：机构趋势线（席位增减仓）、游资连板线（高度与炸板）及跷跷板吸血效应。
3. **二、产业链传导与主线衰竭判定**：链条扩散路径、共振状态、核心主线 SEI 衰竭得分与实战结论。
4. **三、情绪温度与下一交易日切换推演**：5 日情绪走势表格、加权情绪总分、中军与龙头锚点。
5. **四、次日盘前重点跟踪矩阵 (Next Day Watchlist)**：高低切潜力主线、老主线止跌观察、高危回避方向及 9:25 验证关注点。
6. **标的穿透快捷指令**：用户回复 `诊断 [股票代码/名称]`，自动继承本轮动的总量环境与板块状态结论，直通 `stock-analysis`。
7. **跨 Skill 交接摘要**：输出下述 JSON，供次日 `market-prediction` 与 `stock-analysis` 继承：


### 术语白话化规则（强制）
专业术语首次出现必须附一句话白话解释：
- **主线衰竭指数 SEI**（衡量强势题材动能是否被透支、有无高位放量出货风险）；
- **高低切换**（资金从涨幅巨大的高位板块撤出，流向低位还没涨过的同逻辑安全方向）；
- **跷跷板吸血效应**（一个大板块暴涨大量吸纳资金，导致其余题材失血阴跌）。
