## 五、隔夜外力评分模型 ($F \in [-1.00, +1.00]$)

四项得分直接线性累加，不进行二次归一化：

1. **富时中国 A50 (权重 35%)**：$> +0.5\% \rightarrow +0.35$ | $0 \sim +0.5\% \rightarrow +0.15$ | $-0.5\% \sim 0 \rightarrow -0.15$ | $< -0.5\% \rightarrow -0.35$
2. **美股/科技 (权重 25%)**：纳指/费半 $> +1\% \rightarrow +0.25$ | $0 \sim +1\% \rightarrow +0.10$ | $-1\% \sim 0 \rightarrow -0.10$ | $< -1\% \rightarrow -0.25$
3. **中概资产 (权重 20%)**：金龙 $> +1.5\% \rightarrow +0.20$ | $0 \sim +1.5\% \rightarrow +0.08$ | $-1.5\% \sim 0 \rightarrow -0.08$ | $< -1.5\% \rightarrow -0.20$
4. **离岸人民币 (权重 20%)**：USDCNH 明显升值 $\rightarrow +0.20$ | 温和升值 $\rightarrow +0.08$ | 温和贬值 $\rightarrow -0.08$ | 明显贬值 $\rightarrow -0.20$

$$\text{综合外力总分 } F = S_{\text{A50}} + S_{\text{US}} + S_{\text{CN}} + S_{\text{CNH}} \in [-1.00, +1.00]$$

| F 区间 | 外部环境 | 说明 |
|:---:|:---:|:---|
| $+0.50 \sim +1.00$ | 强正向 | 强烈外部利好 |
| $+0.20 \sim +0.50$ | 偏正向 | 温和外部利好 |
| $-0.20 \sim +0.20$ | 中性 | 外部冲击微弱 |
| $-0.50 \sim -0.20$ | 偏负向 | 温和外部压制 |
| $-1.00 \sim -0.50$ | 强负向 | 强烈外部利空 |

必须明确回答：**隔夜外力是否足以改变昨日 A股主要矛盾？**

## 七、概率生成规则与 Pivot 运行区间

### 1. 概率计算规则
- 概率由昨日内生状态 + 外部冲击 $F$ + 指数属性 + 市场情绪综合生成先验概率。
- 满足：$P_{\text{up}} + P_{\text{flat}} + P_{\text{down}} = 100\%$，各概率均在 $[0\%, 100\%]$。
- 概率不是确定性预测。禁止使用“必涨/必跌/稳涨/100%确定”等绝对化词汇。

### 2. Pivot Points 运行区间算法
必须使用 T-1 高 ($H$)、低 ($L$)、收 ($C$) 精确计算，保留合理位：
- **中枢** $P = (H + L + C) / 3$
- **第一压力** $R_1 = 2P - L$ | **第二压力** $R_2 = P + (H - L)$
- **第一支撑** $S_1 = 2P - H$ | **第二支撑** $S_2 = P - (H - L)$

## 八、日内三种路径与 09:25 竞价验证条件

必须生成三个互斥的主要场景（概率和为 100%）：
- **主场景 (40%~60%)**：描述开盘方向、上午路径、P/R1/S1 关系、午后路径及收盘位置。
- **次选场景 (20%~35%)**：描述与主场景明显的不同路径。
- **风险场景 (10%~25%)**：明确触发风险路径的具体条件。

### 09:25 竞价验证三大更新法则：
1. **预测强化**：竞价方向与主场景一致，且竞价明显放量，核心权重同步 $\rightarrow$ 主场景概率提高 $+5 \sim +10\%$。
2. **预测维持**：竞价幅度在 $\pm 0.1\%$ 左右，成交无异常，主逻辑未坏 $\rightarrow$ 概率控制在 $\pm 2\%$ 以内。
3. **预测反转**：竞价方向与主场景严重背离（如看涨但低开明显，竞价爆量放大幅、跌停增） $\rightarrow$ 下调主场景概率 $-15 \sim -25\%$，重新分配。

#### 竞价成交量基准定义：
比率 $= \frac{\text{今日09:25竞价成交额}}{\text{过去20日09:25平均竞价成交额}}$（$\ge 1.20$ 明显放量；$1.05 \sim 1.20$ 温和放量；$0.95 \sim 1.05$ 正常；$<0.95$ 缩量）。若无历史数据标注“未获取”。

4. 概率总和必须始终等于 100%。如果超过 08:30 必须明确标注“非严格回测模式”。
5. 目标是持续建立可验证的概率预测记录，而非仅给出一个“涨/跌答案”。
