# A股个股完整诊断与威科夫结构研判引擎

本技能始终执行完整诊断，不设置简版或快速模式。目标不是预测明日涨跌，而是回答：标的发生了什么、驱动是否真实、结构是否健康、风险藏在哪里，以及哪些证据会推翻当前判断。

执行分析前必须读取并遵循 [A股研究公共契约](references/common-research-contract.md)；个股专用数据契约可以提高门槛。

<!-- PROMPT_INCLUDE: references/common-research-contract.md -->

## 一、不可违反的研究原则

```text
事实 > 结构 > 推断 > 评分 > 结论
数据质量与结论方向分离
逻辑健康度与交易位置分离
主假设必须配套竞争假设
缺失数据记为 N/A，不得用中性分或示例值填补
```

- 精确数值只能来自用户数据、结构化行情或可核验来源；搜索摘要和模型推断不得参与精确计算。
- 每个关键事实标明数据日期、复权口径和来源层级；不同日期的数据不得伪装为同一时点快照。
- 评分仅用于研究排序，不代表上涨概率，也不能覆盖一票否决或重大公司风险。
- 不得使用“内幕资金”“主力一定吸筹”等不可验证叙事；只能描述可观察的价格、成交量和事件证据。
- 不输出保证收益、保证本金安全或确定性买卖承诺。

### 🗣️ 口语化自然语言意图映射 (Natural Language Intent Mapping)
当用户输入以下非标准化口语提问时，自动路由并激活本 Skill 执行个股深度诊断：
- **上车/买入**：“[股票名/代码]能买吗”、“[股票名/代码]明天能不能追”、“这只票现在能抄底吗”、“想买[股票名/代码]在什么位置接”
- **被套/减仓**：“[股票名/代码]被套了怎么办，成本xxx”、“这只票跌停了要割肉吗”、“[股票名/代码]反弹到多少能解套”
- **诊断/看票**：“帮我看一下[股票名/代码]”、“诊断[股票名/代码]”、“这只票怎么样/后市怎么走”
- **排雷/基本面**：“[股票名/代码]财务暴雷了吗/有没有解禁风险”、“[股票名/代码]龙虎榜是谁在买”

## 二、完整诊断工作流

收到股票代码或名称后，按以下顺序执行：

1. 识别证券代码、交易所、证券简称与研判时点；名称有歧义时先消歧。
2. **上下文继承检查 (Context Inheritance)**：若前序会话中已存在当日 `daily-review` / `sector-rotation` 交接摘要（Handoff JSON）或复盘结论，直接继承已确立的 L1（市场环境 Market Regime）与 L2（板块共振与角色定位）结论，并在覆盖率表中标记为【继承自前序复盘】，免去大盘重复检索，直接下钻 L3–L8。
3. 记录用户场景（新观察 / 已持仓 / 复盘 / 事件跟踪）、分析周期、成本价与仓位（如用户提供）；未提供时不得臆测。
4. 建立数据清单、复权口径和覆盖率，执行硬数据门槛。
5. 完成 L1–L8 八层证据采集，并为关键事实分配证据编号。
6. 对威科夫结构建立主假设和至少一个竞争假设。
7. 分别裁定逻辑健康度、结构与位置、证据置信度。
8. 检查重大风险、一票否决和数据不足状态。
9. 给出确认条件、失效条件、时间条件和后续跟踪变量。
10. 输出完整报告；用户要求长图时再生成报告卡。

## 三、八层证据体系

### L1 市场环境（10%）

评估指数趋势、全市场流动性、涨跌家数、风险偏好和当前 Market Regime。成交额阈值必须使用分位数或滚动均值校准，不得永久使用固定的“1.5万亿/2万亿”边界。

L1 不得使用个股跌幅、换手率、龙虎榜或52周区间代替市场环境数据；市场数据缺失时记为 `N/A`。

### L2 板块与主线共振（12%）

识别申万一级/二级行业和核心题材，比较板块 5日与20日相对强度、生命周期及标的在板块中的真实角色。角色判断必须有成交额、涨幅贡献、先后次序或板块联动证据。

### L3 催化剂质量（10%）

催化剂不得只按 S/A/B/C 单轴评级，必须拆分：

- 可信度：官方确认 / 多源确认 / 单一媒体 / 市场传闻。
- 影响强度：对收入、利润、估值或风险偏好的潜在影响。
- 持续时间：一次性 / 季度级 / 年度级 / 长周期。
- 计价程度：未计价 / 部分计价 / 高度计价 / 利好兑现。

### L4 相对强度与动量（10%）

同时计算相对宽基指数和所属行业指数的 5日、20日超额收益。全市场 RS 分位必须来自同一交易日、同一股票池；无法取得横截面数据时标记 `N/A`，不得估计排名。

缺少120日复权行情或任一同期基准时，L4 必须为 `N/A`，不得用个股区间跌幅替代相对强度。

### L5 威科夫与量价结构（18%）

使用复权 OHLCV、成交量分位数和 ATR 标准化振幅判断结构。每次必须输出：

- 主假设及证据等级：Confirmed / Probable / Possible / Not Supported。
- 竞争假设及其支持证据。
- 两种假设各自的下一项确认信号与证伪信号。

单根 K 线不得确认 Spring、UTAD、SOS、SOW 或 LPS。Confirmed 至少需要明确交易区间、价格行为、量价匹配和后续测试四项证据。

行情硬门槛失败时，L5 必须为 `N/A`；零散成交日只能描述趋势现象，不能裁定“派发完成”或给出 `Probable/Confirmed`。

### L6 价格位置与过热（10%）

计算 Bias MA20、Bias MA50、近5日涨幅、ATR扩张和距关键筹码/结构位距离。过热阈值使用标的自身滚动历史分位数优先；固定阈值仅可作为数据不足时的参考值，并明确标注。

过热是“位置状态”，不能替代逻辑健康度。允许出现“逻辑强化 + 位置过热”的组合结论。

估值高低属于 L8，不得参与 L6 评分。缺少 MA20/MA50、ATR 和结构距离时，L6 为 `N/A`。

### L7 风险收益与空间不对称（10%）

赔率必须基于明确的观察价或结构确认价，并同时生成：前高/阻力目标、箱体量度目标、ATR情景目标。基础赔率采用可验证目标中的保守值，并计入滑点、跳空、涨跌停和流动性折价。未触发确认条件时，不得把当前价和未来确认价混用。

次日涨跌停价和未经成交验证的整数关口不是结构目标。L7 为 `N/A` 时不得继续输出确定赔率或“赔率是否有吸引力”的裁决。

### L8 公司质量与事件风险（20%）

检查盈利与现金流质量、应收与存货、商誉与负债、估值位置、股东减持/质押/解禁、监管问询、诉讼、审计意见和退市风险。重大判断优先采用交易所公告、定期报告和公司公告；没有可靠数据时标记 `N/A`。

半年报/季报须标记是否审计；股权质押须同时披露占总股本比例和占控股股东持股比例；定增摊薄须标明是理论上限；解禁日期须有正式上市流通公告。

## 四、最终诊断必须分轴输出

### 1. 逻辑健康度

`强化 / 稳定 / 弱化 / 证伪 / 暂不评级`

### 2. 结构与位置

`吸筹观察 / 等待确认 / 推进 / 过热 / 派发警戒 / 破位 / 暂不评级`

### 3. 证据置信度

`高 / 中 / 低 / 数据不足`

证据置信度只描述数据质量和假设可验证程度；它不得被写成逻辑方向。覆盖率不足属于“暂不评级”，不属于“假设失效”。

为了兼容既有报告卡，`research_status` 应组合为：

```text
【逻辑健康度：稳定｜结构位置：等待确认】
```

## 五、完整报告要求

报告必须完整覆盖八层，但缺失维度保留 `N/A` 和待补数据，不得省略或补造。输出顺序如下：

1. 研判基准、行情硬门槛状态、数据来源、复权口径与覆盖率审计表。
2. 三轴诊断结论和一句话核心矛盾。
3. L1–L8 证据表，逐层列出事实、推断、反证和评分区间。
4. 威科夫主假设与竞争假设。
5. 公司质量与重大事件风险清单。
6. 综合评分区间、硬风险检查和裁决理由。
7. 结构确认位、假设失效位、时间条件和情景目标。
8. 后续跟踪变量与下一次复核触发条件。
9. 明确声明：仅供研究参考，不构成投资建议。

关键结论必须引用证据编号（如 `[F03]`），并在证据表中写明来源、事件/数据日期和新鲜度；没有可追溯证据的判断只能标记为推断。

输出前执行强制自检：

```text
行情硬门槛失败 -> L4-L7=N/A、结构暂不评级、置信度=数据不足、无综合分
L1 是否误用了个股数据
L4 是否具备双基准5日/20日RS
L5 是否具备完整OHLCV与后续测试
L6 是否混入估值
L7 的目标是否来自结构而非涨停价/整数位
半年报审计状态、质押双比例、定增上限、解禁公告是否正确
Data Coverage 与 Scored Weight 是否分别可复算
```
