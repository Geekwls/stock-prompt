# 变更日志 (Changelog)

>
> 详细提交信息可用 `git log` 查看。

## V2.5（当前版本）

### V2.4 → V2.5

| 改动项 | V2.4 | V2.5 | 改动原因 |
|--------|------|------|----------|
| 数据输入分层 | 11 字段一锅端，缺失就跳过对应 Step | **分为 🔴必填 / 🟡建议 / 🟢可选 三层，附 Step 依赖映射表，明确缺失时如何降级** | 新手凑不齐数据时框架应能优雅降级，而非全面瘫痪 |
| Step 11 大盘环境计分 | "上证上涨+放量2分/震荡1分/下跌0分" | **改为 7 种组合判定矩阵，新增"板块独立性补偿"** | 修复"大盘弱时独立主线被系统性低估"（如 2024 初 AI 逆势走强）|
| 极端行情处理 | 仅在边缘情况表里有"大盘暴跌"一条 | **新增第七.五章，4 类极端情况（千股跌停/龙头特停/涨停潮/黑天鹅）的强制响应** | 极端行情下常规评分失效，需绕过流程直接给指令 |
| 多日连续追踪 | 第七章仅有"单次预测追踪表" | **新增 T 日→T+1 日验证工作流、多日追踪表、板块生命周期追踪、修正信号识别** | 单日孤立分析易错判，串联才能验证预测准确性 |
| 文档头部 | 含 V2.5 更新 log | **删除顶部 log，仅保留简介** | 与本 CHANGELOG 重复，减少 token 消耗 |

## V2.4

### V2.3 → V2.4

| 改动项 | V2.3 | V2.4 | 改动原因 |
|--------|------|------|----------|
| 仪表盘综合推荐度示例 | 写"7.7 → 取 7.6"（自相矛盾） | **改为 7.7/10，计算过程一致** | 修复示例笔误，避免 AI 复制错误 |
| 仓位公式示例 | `clamp(7.6/10=0.76) → 7×0.76=5.3` | **改为 `clamp(7.7/10=0.77) → 7×0.77=5.4`** | 同步修复，保持口径一致 |
| 概率推演归一化 | 仅写规则，无示例 | **新增场景A（合计>100%含负值）+ 场景B（合计不足100%）+ 操作要点** | 解决 AI 执行时不知如何归一化的问题 |
| Step 2.5 涨停分上限 | "每家1分，20cm算2分，上限10"（10家20cm是否=20分不清） | **改为 min(10, 10cm家数×1 + 20cm家数×2 + 30cm家数×3)，附示例** | 消除歧义，明确 30cm 计入 |
| Step 12B 龙虎榜机构主导 | "机构净买≥游资×2 且 >5000万"（5000万是单只还是合计不清） | **改为"板块聚合判定"，明确多股龙虎榜时如何合计** | 消除范围歧义 |

## V2.3

### V2.2 → V2.3

| 改动项 | V2.2 | V2.3 | 改动原因 |
|--------|------|------|----------|
| 市场情绪评分 | 缺失 | **新增 Step 0（0-140分）** | 回补 V2.0 的宏观情绪量化，直接决定仓位上限 |
| 驱动等级 | 缺失 | **回补 Step 3（S/A/B/C 级）** | 回补 V2.0，驱动等级决定可持续周期，区分一日游与大行情 |
| 核心研判标准 | 缺失 | **新增 Step 5（结构健康度/一日游/见顶）** | 吸收 gemini 版精华，量化评分前的定性体检 |
| 个股技术评分 | 缺失 | **回补 Step 12C（0-4分）** | 回补 V2.0，股池标的需技术面过滤，低于2分不入池 |
| 次日三情景推演 | 缺失 | **回补 Step 13** | 回补 V2.0 核心功能，连接当日分析与次日操作 |
| 持续性评分边界 | ≥8 / 6-8 / 4-6 三档有交集 | **改为 ≥8 / 6≤x<8 / 4≤x<6 明确区间** | 修复边界重叠 bug |
| 持续性得分"催化剂"项 | 政策2分/事件1分/无0分 | **改为 S级2分/A级1.5分/B级1分/C级0.5分** | 接入 Step 3 驱动等级，消除重复判断 |
| 示例计算口径 | 先算3.5分→修正为4.0分（混乱） | **直接使用正确口径计算 4.0 分** | 避免 AI 执行时困惑 |
| 输出模板 | 13节 | **16节**（新增情绪/驱动/核心研判/股池技术分/次日推演） | 信息完整性 |
| 历史预测追踪 | 无 | **新增第七章（追踪表+异常复盘模板）** | 闭环，建立预测→验证→修正循环 |
| 边缘情况 | 10种 | **13种**（新增情绪<40分/一日游命中≥4条/日内反转踩踏） | 覆盖更多极端场景 |
| 输入数据表 | 无涨跌家数比/红盘率/封板时间/封单额/技术位 | **补全这些字段**，新增连板晋级率 | 支撑新增分析维度 |
| 增强维度"赚钱效应" | 使用昨日涨停红盘率（与基础维度涨停溢价重复） | **改为连板晋级率** | 消除重复计分 |
| 分歧一致输出标签 | 称"市场情绪"（与Step0全市场情绪混淆） | **改为"板块情绪"** | 概念区分 |
| 龙虎榜机构主导定义 | "机构净买入占比>30%"（分母不明） | **改为"机构净买≥游资净买×2且>5000万"** | 消除歧义 |
| 个股技术评分放量阈值 | "放量≥2倍" | **改为"≥1.5倍（当日量≥5日均量×1.5）"，与全文统一** | 消除不一致 |
| 30cm涨跌幅 | 未说明 | **新增北交所30cm说明** | 覆盖全市场 |
| 风险提示输出格式 | 无结构列表 | **改为表格（编号+类型+严重度+触发条件）** | 风险可分级可追溯 |
| 示例 | 仅正面案例 | **新增反面案例（一日游高风险输出形态）+ 仪表盘示例 + 概率计算示例** | 演示高风险时的强制降级逻辑及完整输出 |
| 多板块对比 | 无 | **新增 Step 2.5（5维加权排名 + 跷跷板判断 + 资金分配规则）** | 多主线并存时须量化排名 |
| 概率推演 | 纯主观估百分比 | **新增概率推演公式（12因子贝叶斯式调整 + 归一化规则 + 计算示例）** | 概率不能凭空想象 |
| 综合评分仪表盘 | 无 | **新增第十七章输出（16维总览 + 综合推荐度公式 + 仓位量化公式）** | 一页看清全局，算分明再下手 |
| 仓位量化 | 定性"轻/中/重" | **改公式：情绪上限 × clamp(综合推荐度/10, 0.3, 1.0)** | 分数直接映射到成数 |
