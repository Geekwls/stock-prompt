# 诊断裁决与评分规则

## 分层评分

每层使用区间而非单点伪精确值：

| 等级 | 分数区间 | 含义 |
|---|---:|---|
| A | 85–100 | 多项高质量证据同向，关键反证较弱 |
| B | 70–84 | 主要证据成立，存在可管理的不确定性 |
| C | 55–69 | 证据分化，必须等待关键确认 |
| D | 30–54 | 负面证据占优或结构明显弱化 |
| E | 0–29 | 核心假设已被高质量证据推翻 |
| N/A | 不计分 | 数据不足，不得以60分代替 |

权重为：L1 10%、L2 12%、L3 10%、L4 10%、L5 18%、L6 10%、L7 10%、L8 20%。仅在覆盖率不低于70%且关键行情门槛满足时计算综合区间。若存在 N/A，按可评分权重归一化，并明确实际参与评分的权重；L5、L7或L8任一为 N/A 时，不得给出“高置信度”。

## 双轴裁决

### 逻辑健康度

- 强化：经营/催化/板块与量价中至少三类高质量证据改善，且无重大反证。
- 稳定：核心假设仍成立，但新增证据不足以升级。
- 弱化：经营、催化、相对强度或量价出现持续负反馈。
- 证伪：预先定义的核心事实或结构失效条件已经发生。
- 暂不评级：关键数据缺失或时点无法对齐。

### 结构与位置

- 吸筹观察：存在交易区间和需求迹象，但尚未完成确认。
- 等待确认：主假设合理，仍缺突破、测试或承接证据。
- 推进：趋势和量价配合，未触发过热或派发警报。
- 过热：偏离度、ATR扩张或短期涨幅进入自身历史极端分位。
- 派发警戒：高位供应证据增强，但尚未完成破位确认。
- 破位：关键结构位被有效跌破并得到量价或后续走势确认。
- 暂不评级：行情门槛不满足。

逻辑健康度与结构位置可以任意组合，不得互相覆盖。

## 证据置信度

- 高：覆盖率不低于85%，关键数据新鲜且至少六层证据可核验，无重大来源冲突。
- 中：覆盖率70%–84%，或存在一项重要但非致命矛盾。
- 低：覆盖率虽达70%，但来源质量较弱、时点错位或竞争假设接近主假设。
- 数据不足：覆盖率低于70%或行情硬门槛失败。

## 硬风险与裁决上限

公司风险分级统一为：`低 / 中 / 高 / 极高 / N/A`。低风险表示当前未见重大异常；中风险表示存在需跟踪事项；高风险表示已有实质性不利因素；极高风险表示可能影响持续经营、交易资格或资本安全。高风险时逻辑健康度最高为“稳定”，极高风险或退市/造假证据成立时不得给出“重点跟踪”式正向结论；风险数据不足时只能为 `N/A`，不能默认为低风险。

以下情况不自动等于“公司没有研究价值”，但必须单列并限制正向结论：

- 非标准审计意见、重大财务造假或明确退市风险。
- 重大诉讼、监管立案或控制权风险尚未消除。
- 高比例质押、集中解禁或减持与流动性脆弱叠加。
- 威科夫派发得到确认或关键结构有效破位。
- 赔率低于1.5:1，或目标位无法由可验证方法得到。

覆盖率不足不是硬风险，也不是假设失效，只能判为暂不评级。

## 复核触发与结论变更

报告末尾必须列出下一次复核触发条件，至少覆盖：关键结构位突破或跌破、突破后测试失败、MA20 失守且反抽失败、新财报/重大公告、行业龙头负反馈、相对强度连续 3 个交易日跌破中位数。若提供上一份报告，应比较逻辑健康度、结构位置、公司风险和新增/失效证据，并明确结论发生变化的原因。

## 威科夫竞争假设

每次至少比较两个解释。例如：

```text
主假设：Markup 中继
竞争假设：高位再派发
主假设证据：突破有效、回踩缩量、行业RS维持
竞争假设证据：高位成交量分位上升但价格效率下降
下一确认：放量突破区间上沿并出现缩量LPS
下一证伪：放量跌破区间下沿且反抽失败
```

“成交量极大/极小”和“振幅宽/窄”必须相对最近60或120个交易日分位数表达；Spread 优先使用 ATR 标准化。

## 赔率规则

1. 明确计算基准是当前观察价还是未来确认价。
2. 分别计算前高/阻力、箱体量度、ATR情景三种目标。
3. 取有证据支持目标中的保守值作为基础目标；其余作为乐观情景，不参与基础评级。
4. 下行风险以结构失效位为基准，同时考虑预估滑点、跳空和跌停无法成交风险。
5. 无可靠失效位或目标位时，L7 为 N/A，不得强造赔率。

## 时间与退出纪律

时间条件由分析周期、结构阶段和催化半衰期共同决定，不能仅由催化等级机械映射。退出条件分为：

- 预警条件：负面信号出现，但核心假设尚未证伪。
- 结构失效：关键结构位有效破坏，研究假设降级或证伪。
- 事件失效：公告或经营事实推翻催化逻辑。
- 时间失效：在预定观察窗口内未出现应有确认信号。
- 盈利保护：仅描述调整研究失效位，不得宣称“确保本金零风险”。

用户询问持仓处理时，应结合其成本、仓位、持有周期和风险承受能力；未取得这些信息，只能提供条件情景，不能给个性化仓位比例。

## A股特殊风险检查

至少检查：T+1、涨跌停与一字板流动性、ST/退市风险、停复牌、除权复权、上市未满120日、可转债或定增稀释、解禁减持、北交所/科创板/创业板交易规则差异。
