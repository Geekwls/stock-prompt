## 🏛️ 四大核心支柱设计

### 1. 🧭 支柱一：智能时段感知与意图总路由 (Time & Intent Gateway)
- **时段感知调度契约**：
  - `08:30 – 09:15`：默认唤醒 `market-prediction`，输出大盘三态分布、关键阻力支撑与机会函数分。
  - `09:25 – 09:30`：输入“9:25/竞价”时，自动调度 `market-prediction` 执行竞价三维贝叶斯后验更新。
  - `15:00 – 21:00`：默认唤醒 `daily-review`，复盘全天领涨板块产业链共振，并自动对比早盘预测计算校准度。
  - `周五收盘 / 周末`：默认推荐 `sector-rotation`，复盘近 5 日资金迁移矩阵与主线生命周期。
  - `股票代码 / 名称`：任意时段输入（如 `000938` / `中际旭创`），自动唤醒 `stock-analysis` 进行八层证据深度诊断。

---

### 2. 🎯 支柱二：盘前 ↔ 盘后预测校准闭环 (Prediction ↔ Review Calibration)
- **预测快照规范 (`Prediction Snapshot`)**：
  盘前推演完成后，输出标准化轻量 JSON 预测快照至会话上下文：
  ```json
  {
    "date": "2026-09-01",
    "predicted_regime": "S3",
    "forecast_prob": {"Up": 0.55, "Side": 0.30, "Down": 0.15},
    "predicted_range": {"R1": 3885, "S1": 3840},
    "opportunity_score": 78,
    "top_themes": ["CPO光通信", "PCB覆铜板", "低空经济"]
  }
  ```
- **盘后自动校准矩阵 (`Calibration Engine`)**：
  独立 Calibration Engine 消费 Prediction Artifact 与 CloseActual Artifact，评估：
  - **大盘点位命中率**：收盘价是否落在 $[S_1, R_1]$ 预估波动区间。
  - **主线命中率 (Hit Rate)**：早盘推演的前 3 主线是否有 $\ge 2$ 个进入全市场实际领涨 Top 10%。
  - **概率精确度 (Brier Score)**：量化输出三态概率预测的均方误差（$Brier = \frac{1}{N} \sum (f_t - o_t)^2$）。

---

### 3. 🔗 支柱三：板块到个股的一键深度穿透 (Sector ➡️ Stock Propagation)
- **快捷穿透入口**：
  `daily-review` 与 `sector-rotation` 输出的每个领航龙头与中军标的均带有穿透参数：
  > 📌 **标的穿透池**：
  > 1. `中际旭创 (300308)` — [CPO中军 ｜ 强化期 ｜ 资金延续 88分] ➡️ *回复 `诊断 300308` 深度穿透*
  > 2. `沪电股份 (002463)` — [PCB核心 ｜ 启动期 ｜ 资金延续 82分] ➡️ *回复 `诊断 002463` 深度穿透*
- **减少重复采集机制 (Context Reuse)**：
  `stock-analysis` 可复用最近有效交接中的 Layer 1（大盘环境）和 Layer 2（板块共振）候选证据，但必须核验时点、来源、口径和覆盖率；冲突或过期时独立补采并重新裁决。不承诺未经测量的固定提速倍数。

---

### 4. 📱 支柱四：完整分析的精简展示层 (Mobile Summary View)
- **展示层边界**：单屏内容来自已经完成的完整分析，只压缩表达，不减少数据门槛、证据审计或竞争假设；个股诊断仍不提供快速/简版分析模式。
- **单屏极简交付**：
  - 盘前：大盘三态分布条 + 今日机会分 + 核心关注主线（1 屏内）。
  - 盘后：主线排行榜 + 中军标的池 + 避险提示（1 屏内）。
  - 个股：30 秒核心结论表 + 3 大关键位 + 证伪纪律（1 屏内）。

## 🛠️ 四阶段实施路线图 (Implementation Phases)

